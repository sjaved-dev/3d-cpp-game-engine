# 3D First-Person Simulator & Game Engine from Scratch
**BSc Computer Science Capstone Project | University of Management and Technology**  
*Awarded Grade: A / A-*

### 🎮 Project Summary
A low-level, high-performance modular 3D simulation environment and rendering engine architected completely from scratch utilizing native C++ and pure Object-Oriented Programming (OOP) design patterns.

### ⚙️ Engine Sub-System Implementations
- **Dynamic Object Pooling:** Programmed real-time runtime memory optimizations that recycle entity allocation fields, completely eliminating heap fragmentation and garbage collection latency spikes on resource-constrained hardware profiles.
- **Spatial Partitioning & Collision Grids:** Designed low-latency bounding box collision detection routines using custom mathematical matrix vector transformations without relying on external third-party physics libraries.
- **Thread Architecture:** Structured decoupled execution arrays separating rendering loops, physics update phases, and basic automated entity behavioral logic loops.
